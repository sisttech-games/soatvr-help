# Central de Informação do SOATVR

Central de guias, catálogo de imersões e atualizações do projeto SOATVR.

Site estático em HTML, CSS e JavaScript, com imagens e documentos de consulta incluídos.

## Publicação no GitHub Pages

Nas configurações do repositório, abra Pages, selecione Deploy from a branch e escolha a branch main com a pasta raiz. O arquivo .nojekyll permite servir os arquivos diretamente.

## Editar o conteúdo

- content.js reúne os tutoriais, o FAQ, os links e as notas de atualização.
- catalog.js contém as fichas pesquisáveis das imersões.
- index.html e style.css definem a interface.
- app.js implementa a busca e a navegação.
- assets contém as imagens da Central.
- documentos contém os materiais de consulta.

As alterações publicadas na branch main ficam disponíveis após a conclusão da publicação do GitHub Pages.


## Catálogo original

O PDF original do catálogo está anexado à [versão de testes v1.0.0](https://github.com/sisttech-games/soatvr-help/releases/tag/v1.0.0). O botão de catálogo da Central aponta para esse download. Os outros PDFs ficam na pasta documentos.
